# Spam SMS Detection

A professional Machine Learning project to detect Spam and Ham SMS messages using Python, Flask, Scikit-learn and TF-IDF.

## Features

- SMS Spam Detection
- Text Preprocessing
- TF-IDF Vectorizer
- Naive Bayes Classifier
- Flask Web Application
- Responsive UI

## Project Structure

```
Spam_SMS_Detection/
│
├── app/
├── data/
├── models/
├── src/
├── requirements.txt
├── README.md
└── main.py
```

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python src\data_preprocessing.py
python src\train_model.py
cd app
python app.py
```

Open:

```
http://127.0.0.1:5000
```
